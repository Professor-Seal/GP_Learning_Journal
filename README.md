## 16/10/25
Deciding on what my 4 components for my protype would be. These are a button that opens and closes a door, a switch that changes the perception for the player, player movement including left, right and the ability to go up walls and enemy projectiles that damage/ kill the player.

Had an error message appear relating to the packet manager. To rectify this issue I select the remove option for the JetBrains Rider Editor. This seems to have fixed the problem. I did this for all 4 prototype Unity files.
